# Problem:
Physical limitation & risks imposed from overreliance of physical documentation for OJT evaluation(internship eval)
Physical archiving works of student’s OJT evaluation is slow, takes up a lot of physical space and promotes paper wastage
# Solution:
Create a program which provides an online cloud functionality that’s specifically catered for the management, search and edition of student OJT evaluation(internship eval) records
# Impact: 
18/20(‭90‬%) lecturers says the quality of the OJT’s report received improve significantly
20/20(‭100%) lecturers says it reduces significantly the time to search for student’s OJT record compared to physical archive
Development time: 25/12-current(98 days)
